# THE MONSTER — 3D хоррор

Браузерная 3D-хоррор-игра на Three.js. Без сборки и зависимостей — просто открой `index.html`.

## Как играть

1. Открой `index.html` (нужен интернет для загрузки Three.js с CDN).
2. Собери **6 предохранителей** 🔋 в тёмном лабиринте.
3. Найди дверь с красной лампой — после сбора всех предохранителей она откроется (лампа станет зелёной).
4. Не дай монстру подойти. Он слышит шум твоих шагов и **видит свет фонарика**.

## Управление

| Клавиша | Действие |
|---|---|
| `WASD` | движение |
| `Мышь` | осмотр |
| `Shift` | бег (тратит выносливость) |
| `F` | фонарик вкл/выкл (батарея ограничена) |
| `Esc` | пауза |

## Механики

- **Фонарик** — видимость, но монстр замечает свет с большего расстояния.
- **Батарейки** — разбросаны по лабиринту, восстанавливают заряд (+55%).
- **Монстр** — патрулирует, преследует при обнаружении, ускоряется с каждым собранным предохранителем и телепортируется ближе, если отстал.
- **Звук** — эмбиент-дрон, сердцебиение при приближении монстра, рык при обнаружении — всё синтезируется через WebAudio, без аудиофайлов.
- Лабиринт генерируется заново каждую игру.

## Технологии

- Three.js r160 (CDN, ES-модуль)
- Чистый JavaScript, без сборщиков
- WebAudio API для звука

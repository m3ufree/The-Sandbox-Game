# THE SANDBOX GAME

Браузерная 3D песочница на Three.js. Никаких монстров — просто строй свой мир: ставь объекты, взрывай ТНТ, меняй день и ночь.

**Играть:** https://m3ufree.github.io/The-Monster-Game/

## Карты
- 🏨 **Двор** — лабиринт из заборов и стен
- 🌲 **Лес** — открытая поляна с деревьями
- 🏙️ **Заражённый город** — улицы и кварталы
- 🦢 **Село Сулоаоу** — смешанная деревня с домами, колодцами и стогами

## Управление (ПК)
| Действие | Клавиша |
|---|---|
| Движение | WASD |
| Бег | Shift |
| Осмотреться | Мышь (клик по экрану) |
| Поставить объект | ЛКМ |
| Удалить объект | ПКМ или X (ТНТ при этом взрывается) |
| Выбор объекта | 1–8 или колесо мыши |
| День / Ночь | T |
| Фонарик | F |
| Прыжок | Space |
| Сесть / выйти из машины | E (рядом с машиной) |
| Пауза | Esc |

Дома в селе можно заходить внутрь через дверной проём. Машиной можно управлять: WASD — газ и руль, камера следует за машиной.|

## Объекты
📦 Ящик · 🛢️ Бочка · 🚗 Машина · 🌳 Дерево · 🏮 Фонарь · 🌾 Стог · ⛲ Колодец · 💥 ТНТ

Взрыв ТНТ разлетает все объекты поблизости с физикой (гравитация, отскоки, трение).

## Сохранение (XML)
В паузе (Esc / ⏸):
- **💾 Сохранить** — карта сохраняется в браузере (XML в localStorage)
- **📂 Загрузить** — загрузить сохранённую карту
- **⬇️ Скачать XML** — скачать карту файлом `sandbox-map.xml`
- **⬆️ Открыть XML** — загрузить карту из файла

Автосохранение происходит каждые 20 секунд и при выходе из игры. Формат файла:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<sandbox map="village" night="0" px="6.00" pz="6.00" yaw="2.356">
  <object type="car" x="12.00" y="0.00" z="10.00" ry="0.000"/>
  <object type="tnt" x="20.00" y="0.00" z="6.00" ry="1.571"/>
</sandbox>
```

## Управление (телефон)
- Джойстик слева — движение, свайп справа — осмотр
- ➕ поставить объект, 🗑️ удалить ближайший, 🚗 сесть/выйти из машины, 🌓 день/ночь, ⏸ пауза
- В вертикальной ориентации игра встаёт на паузу — переверните телефон

## Технологии
- Three.js r160 (ES-модуль с CDN, без сборки)
- Все звуки синтезируются через WebAudio API — файлов нет
- Работает на ПК и мобильных, GitHub Pages
